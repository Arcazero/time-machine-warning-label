A one-line warning label for a time machine, written for make.fun's "Funniest Time Machine Warning Label" bounty. It turns the classic time-travel hazard — running into your own duplicate self — into the joke, phrased like a genuine safety notice, with the punchline saved for the last few words:

> WARNING: If you meet yourself, do not make eye contact. He knows what you did.

## Run it

```sh
python3 main.py
```

This writes the label (78 characters) to `/output/entry.txt`.
